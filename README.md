# Pete’s BP to Garmin

A personal Windows project for retrieving my own blood-pressure and pulse readings from iHealth Cloud and preparing Garmin FIT files for manual import into Garmin Connect.

## Purpose

Bring my readings together for personal trend tracking and discussion with healthcare professionals.

## Status

Historical CSV-to-FIT conversion has been tested. Direct iHealth API integration is under development.

## Privacy

This website contains project information only. Health readings, account credentials and authorization tokens are not published here.

The integration is intended for my personal use and is not a public service or a diagnostic tool.
